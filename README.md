# Дарья Ульянова — QA Engineer

Практикующий QA с опытом тестирования и сопровождения корпоративного ПО. Самостоятельно исследую новый функционал, проверяю пользовательские и интеграционные сценарии, воспроизвожу и локализую дефекты, работаю с логами и сопровождаю исправления до ретеста.

Сейчас развиваюсь в сторону более технического QA: API, SQL, DevTools, Git и тестирование мобильных приложений.

## Что делаю в коммерческой работе

- functional / regression / smoke / integration / acceptance testing;
- exploratory и black-box testing при неполной документации;
- воспроизведение и локализация дефектов на разных окружениях;
- анализ логов и первичная диагностика технических проблем;
- оформление bug reports: steps, expected/actual result, environment, severity/priority, артефакты и workaround;
- retest исправлений и проверка смежного функционала;
- проверка установок, обновлений и интеграций;
- взаимодействие с разработчиками и технической поддержкой.

## Что удалось улучшить

- внедрила обязательную smoke-проверку после обновлений, чтобы выявлять проблемы до массовой установки у клиентов;
- стандартизировала оформление дефектов, что по рабочей оценке сократило типичный цикл решения примерно с **5–7 до 1–3 дней**;
- привыкла не просто фиксировать симптом, а собирать данные для локализации и доводить дефект до подтверждённого исправления.
